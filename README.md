# 待产准备指南 Skill

一个全面的待产准备参考指南，帮助准父母系统化地准备迎接新生命。

## 概述

这个 Skill 提供了从孕晚期到产后恢复的完整流程指导，包括：

- 🏥 **孕晚期日常观察**：症状识别、自我监测阈值
- 🎒 **待产包清单**：证件、妈妈用品、宝宝用品
- 🚨 **临产识别**：见红、宫缩、破水的判断标准
- 👨‍👩‍👦 **分娩准备**：产程概览、入院流程、准爸爸行动指南
- 🌸 **产后恢复**：42天检查、恢复时间线
- 👶 **新生儿护理**：喂养、睡眠、日常护理、疫苗接种
- 📝 **证件办理**：户口、医保、生育补贴申请流程

## 适用场景

- 准父母询问待产准备事项
- 需要系统的待产包清单
- 学习如何识别临产信号和判断何时去医院
- 了解分娩流程和准爸爸在分娩过程中的角色
- 产后恢复和新生儿护理指导
- 证件办理和生育补贴申请流程咨询

## 核心特性

### 1. 清单化管理

所有准备工作都以清单形式呈现，方便逐项检查：

- ✅ 待产包清单（证件/妈妈用品/宝宝用品）
- ✅ 入院速查清单（出发前/到院后/入病房后）
- ✅ 时间线待办清单（产前/出院前/产后1个月/产后42天）

### 2. 红线信号系统

明确的"立即就医"判断标准：

- 🚨 孕晚期警惕症状
- 🚨 妈妈产后危险信号
- 🚨 新生儿就医信号
- 🚨 爸爸红线清单（何时立刻叫医护）

### 3. 准爸爸行动指南

专为准爸爸设计的实用指南：

- 📋 临产当天口袋卡（12条铁律）
- 🔴 红线清单（立刻叫医护的情况）
- 💬 产房门口沟通四句模板
- 📅 分娩当天流程细化（按时间段）

### 4. 时间线驱动

按时间顺序组织待办事项，不错过关键时间窗口：

- ⏰ 黄金时间窗口（早开奶、新生儿医保、盆底康复、育儿补贴）
- 📅 产前、出院前、产后1个月、产后42天的待办清单
- 🗓️ 疫苗接种时间表

### 5. 证件办理流程

详细的证件和补贴办理指导：

- 📄 办理顺序（8个步骤）
- 📋 所需材料清单
- 💰 生育报销与补贴申请
- ⚠️ 避坑指南

## 使用方法

### 在 Claude Code 中使用

将此 Skill 放入 `~/.claude/skills/` 目录后，Claude 会自动在相关场景下加载。

### 触发场景

当用户询问以下内容时，Claude 会自动使用此 Skill：

- "待产需要准备什么？"
- "什么时候该去医院？"
- "如何判断是真宫缩还是假宫缩？"
- "准爸爸在分娩时该做什么？"
- "新生儿怎么护理？"
- "宝宝户口和医保怎么办理？"
- "生育补贴怎么申请？"

## 脱敏说明

本 Skill 已完全脱敏，移除了：

- ❌ 个人姓名
- ❌ 具体地址（如"昌平"等地点信息）
- ❌ 医院名称（改为"医院产科急诊"）
- ❌ 个人联系方式
- ❌ 具体社区名称

所有内容均为通用性指导，可安全开源使用。

## 重要提醒

⚠️ **本指南为通用参考，具体情况请遵医嘱**

- 医疗建议仅供参考，具体诊疗请咨询医生
- 证件办理流程和补贴标准因地区而异，办理前请电话咨询当地部门确认
- 各地医院政策不同，入院流程以当地医院为准
- 建议打印核心清单（待产包、临产识别、爸爸口袋卡）随身携带

## 核心清单速查

### 何时去医院

- ⚠️ **破水** → 立即去（躺着去）
- ⚠️ **大量出血** → 立即去
- **规律宫缩每10分钟** → 可以去
- **宫缩3-5分钟持续30-60秒** → 必须去

### 5-1-1 宫缩法则

- 每 **5** 分钟一次宫缩
- 每次持续约 **1** 分钟
- 连续维持约 **1** 小时
- → 建议入院评估

### 黄金时间窗口

- 🕐 **早开奶**：产后1小时内
- 📋 **新生儿医保**：取得户籍后90天内
- 🏥 **42天检查**：产后42-56天
- 💰 **育儿补贴**：每年申请一次，不申请视为放弃

### 准爸爸必记3句话

1. "我们有无痛需求，请尽快评估条件。"
2. "若有风险变化，请第一时间通知我签字。"
3. "宝宝出生后请提醒我们先做皮肤接触和尽早开奶。"
